# 🏷️ Генератор ценников

Программа для Windows, которая создаёт ценники из таблицы Excel. Разработана для магазина в СНТ «Алмаз» и рассчитана на принятый в нём формат таблицы.

Ценники содержат название товара, цену в рублях и единицу измерения. Программа размещает их на страницах и сохраняет в PNG для печати на листах А4.

## Запуск

Скачайте ZIP-архив из [последнего релиза](https://github.com/Dasplet-gh/price-tag-generator-for-almaz-store/releases/latest), распакуйте его и запустите `Генератор ценников для магазина Алмаз.exe`.

## Формат таблицы

Используется первый лист файла Excel `.xlsx`. Первая строка — заголовки, со второй строки — по одному товару на строку.

| Столбец | Содержимое |
| --- | --- |
| A | Название товара |
| C | Единица измерения: например, `кг`, `шт` или `л` |
| G | Цена в рублях, числом |

Остальные столбцы не используются.

## Настройки

Перед выбором таблицы можно настроить:

- Количество строк и столбцов ценников на странице.
- Толщину рамки ценников.
- Отступы от краёв страницы.

После обработки таблицы программа предложит выбрать папку для сохранения PNG.
